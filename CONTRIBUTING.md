# Contribuir a ALASTHEO

## Flujo

1. Crea una rama desde `main`.
2. Realiza un cambio coherente y acotado.
3. Conserva fuentes, exports y evidencia en sus carpetas correspondientes.
4. Ejecuta las validaciones disponibles antes de integrar.
5. Abre un Pull Request explicando qué cambió y qué evidencia permite revisarlo.

## Para cambios 3D

Incluye cuando sea posible:

- versión anterior y nueva;
- archivo fuente;
- export `.glb`;
- vistas frontal, lateral y 3/4;
- cambios principales;
- problemas conocidos;
- resultado de validaciones automáticas.

## No incluir

- cachés locales;
- entornos virtuales;
- backups automáticos de Blender;
- archivos temporales del sistema;
- duplicados con nombres ambiguos.
